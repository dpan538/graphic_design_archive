# Seed Data v0

This directory contains the first structured seed files for the Modern Graphic Design History Archive Index.

Public status:

- This directory is part of a public research-code backup, not a final publication dataset.
- Seed files, candidate records, capture rows, raw capture snapshots, generated summaries, and source stubs are implementation-stage materials.
- Raw capture files and capture summaries are reproducibility evidence for the project pipeline, not source mirrors.
- Candidate rows should not be cited as final evidence unless source terms review, rights review, field provenance, and citation review have been completed for the specific record.
- GitHub backup does not imply rights clearance, source permission, publication approval, or scholarly completeness.

Source basis: `Rights-Aware Archive Index Framework for Modern Graphic Design History.docx`, reviewed in the project folder on 2026-05-29.

Generated by: `scripts/generate_seed_data.py`

Global coverage supplements generated by:

- `scripts/generate_regional_coverage_data.py`
- `scripts/generate_global_coverage_data.py`

Files:

- `historical_nodes.csv`: initial historical spine and node map.
- `movements.csv`: movements, formations, schools, regimes, and counter-historical groupings.
- `media_technologies.csv`: media, processes, technologies, and formats.
- `source_registry.csv`: candidate source universe with access, automation, rights-basis, and first-ingest source notes.
- `search_vocabulary.csv`: deterministic search vocabulary seed, including first-ingest query profiles and script variants.
- `rights_strategy.csv`: rights-safe indexing and display rules.
- `regions.csv`: launch-scope macro regions and regional contexts.
- `coverage_matrix.csv`: region × historical-node coverage tracking.
- `regional_source_priorities.csv`: source needs by region.
- `classification_axes.csv`: required classification axes for records and API filters.
- `geographies.csv`: countries, territories, regions, and historical/context geographies.
- `regional_movements.csv`: launch-scope regional movements, formations, schools, media cultures, and first-ingest movement cells.
- `regional_event_nodes.csv`: dateable regional historical nodes that connect geography, movement, source needs, and first-ingest anchors.
- `experimental_ingest_shortlist.csv`: 39 candidate records/source cases, including 24 source/right behavior tests and 15 first-ingest scope cells.
- `first_ingest_record_targets.csv`: 48 concrete target records or deterministic search paths for the first controlled ingest verification set.
- `first_ingest_target_verifications.csv`: mechanical verification decisions for the first 48 targets, including ready/manual/link-only/search-path/replacement/browser-recheck status.
- `ready_manual_ingest_targets.csv`: generated ready subset exported from target + verification rows; this is the input candidate list for manual source record drafting.
- `manual_source_records_index.csv`: generated index of the first 30 valid manual source record drafts.
- `manual_source_records/*.json`: candidate manual source record drafts generated from the ready subset. These are not final ingested records.
- `fallback_source_stubs.csv`: generated stubs for the 18 first targets that cannot yet become source records. These preserve the historical area and source/search link without ingesting the material.
- `source_redundancy_candidates.csv`: 90 report-derived alternate candidates, six per first-ingest cell.
- `source_redundancy_triage.csv`: 18 report-derived triage recommendations for fragile/failed source paths.
- `recommended_six_target_ingest_sets.csv`: recommended six-target ingest set per first-ingest cell.
- `fallback_remediation_recommendations.csv`: remediation recommendations from the unresolved-target report.
- `fallback_remediation_projection.csv`: projected state of the 18 fallback stubs after remediation verification.
- `global_source_expansion_candidates.csv`: 84 source expansion candidates from the global source-expansion report.
- `first_production_low_friction_sources.csv`: 20 source candidates recommended for production-first ingest.
- `high_value_fragile_sources.csv`: 20 valuable sources that should remain backup, link-only, or fallback-first.
- `remediation_source_verifications.csv`: 10 source-level verification rows for unresolved first-ingest fallback targets.
- `remediation_source_records_index.csv`: generated index of 8 valid remediation candidate source-record drafts.
- `remediation_source_records/*.json`: candidate source-record drafts generated from remediation verifications. These are not final ingested records.
- `capture_batch_001_records.csv`: 50 API/search-result rows from the first production capture batch.
- `capture_batch_001_source_summary.csv`: direction/source/image-state summary for capture batch 001.
- `capture_batch_001_cell_assignments.csv`: row-level assignment from captured candidate to existing cell, proposed new cell, or unassigned pool.
- `capture_batch_001_cell_summary.csv`: cell-level collection summary after filtering capture batch 001.
- `capture_batch_001_next_generation_queue.csv`: next-generation queue derived from empty existing cells, proposed new cells, and unassigned rows.
- `capture_batch_001_raw/*.json`: raw API payloads preserved for reproducibility of capture batch 001.

Status:

- These files are implementation seeds, not final scholarly authority.
- Authority IDs, jurisdiction-specific copyright review, and source-specific terms review remain pending.
- Images should not be ingested from these sources unless the relevant rights fields and source terms clearly allow it.
- `IMG00` keeps the fixed image area but renders an empty archive frame only: no source image, thumbnail, screenshot, preview, or local copy.
- `IMG00` through `IMG03` assume an image frame exists and are resolved by copyright/display permission.
- `IMG04` is a pure text page with no image frame. It is a script/template signal, not a copyright level. Image zone codes describe image presence state, not size.

The first 48 record targets are preserved as a reviewed planning set in `first_ingest_record_targets.csv`, `first_ingest_target_verifications.csv`, `INGEST_CONTRACT_AND_TARGETS_REVIEW_v0.md`, and the source report docx. They are not treated as ingested records until each target receives source terms review, rights review, source metadata capture, citations, and field provenance.

The first manual source record draft pass is documented in `MANUAL_SOURCE_RECORD_DRAFTS_v0.md`. Draft records are valid candidate records, but source fields still need page-level capture and field provenance before publication use.

Fallback source stubs are deliberately not source records. They are link/search/status records for unresolved, blocked, replacement, or page-level-recheck targets. They keep the archive framework intact without pretending the project has captured evidence it does not yet hold.

The source redundancy and source expansion CSVs are Deep Research outputs. They are reviewable candidate data, not automatically approved source records or registry entries.

The remediation source-record drafts show how fallback stubs can be promoted or replaced without losing uncertainty. Contextual candidates must remain visibly marked as contextual, and the two blocked rows remain fallback stubs until exact source evidence or a reviewed bibliographic anchor is available.

The capture batch rows are production candidate rows in a staged archive workflow: raw capture, image-state evaluation, cell assignment, cell summary, next-generation queue, and later source-record generation after review.
