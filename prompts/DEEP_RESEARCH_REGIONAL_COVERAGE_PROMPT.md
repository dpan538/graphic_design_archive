# Deep Research Prompt: Regional Coverage Expansion

I am developing a project defined as:

**A rights-aware archive index and research framework for modern graphic design history.**

The project must avoid becoming an Euro-American framework with decorative global additions. It should pursue broad, systematic, gap-aware coverage across Europe, the Americas, Japan, Korea, East Asia, Mainland China, Hong Kong, Taiwan, and other global regions.

The project does not claim complete coverage, but it aims to map as much known graphic design development as possible through a reproducible structure of regions, historical nodes, movements, media technologies, sources, events, and search terms.

Current seed framework includes:

- 15 historical nodes;
- 38 movements/formations;
- 35 media/technology/format terms;
- 35 source candidates;
- 15 regions;
- 225 region-node coverage matrix rows.

Please conduct a deep research study that expands the regional coverage framework.

## Required Launch Regions

All of these regions belong to the first launch scope. Do not separate them into launch phasing.

## Research Tasks

### 1. Regional Historical Node Maps

For each region, map major graphic design history nodes from print preconditions to contemporary digital/platform culture.

For each node, provide:

- region;
- node name;
- date range;
- key cities;
- key media/technologies;
- key object types;
- key institutions/schools;
- key designers/studios/collectives;
- key publications/periodicals;
- key exhibitions/events;
- source types;
- search terms in local language and English;
- rights/access issues;
- confidence level;
- notes on gaps.

### 2. Regional Movement and Formation Taxonomy

For each region, list known movements, schools, tendencies, studios, publishing cultures, political graphic formations, typographic developments, and digital/interface formations.

Do not only list canonical art movements. Include:

- commercial print cultures;
- state design;
- propaganda/public information;
- magazine and editorial cultures;
- typography/script-specific formations;
- corporate identity;
- protest graphics;
- feminist/queer/labor/decolonial graphics;
- vernacular design;
- digital/web/platform visual cultures.

### 3. Regional Event Layer

Create an event-level framework.

Include:

- school foundings and closures;
- major exhibitions;
- journal/magazine launches;
- poster campaigns;
- state/public information campaigns;
- design association foundings;
- design awards;
- corporate identity launches;
- typeface releases;
- software/platform events;
- important publication dates;
- major political/social campaigns with graphic output.

For each event:

- event name;
- event type;
- date/date range;
- city/region;
- related movement/node;
- source/citation candidate;
- confidence;
- rights/access notes.

### 4. Regional Source Registry Expansion

- national libraries;

- poster archives;

- periodical archives;
- web archives;
- community archives;
