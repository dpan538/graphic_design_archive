# Authoritative Exploration definition

Exploration Field is a non-object-facing system for composing, arranging, and exploring possible design-historical relation concepts as nodes, flows, clusters, branches, and tree-map structures. Its purpose is research inspiration.

It does not expose archive records, object titles, thumbnails, identifiers, detail links, related records, similar works, or recommendations. A conceptual node cannot open a record merely because it exists in a composition.

Exploration does not derive semantics from archive medium, theme, movement context, date, geography, creator, object type, source, descriptive metadata, Context projection, or Spacetime projection. Those systems remain separate.

Similarity, affinity, nearest-neighbor retrieval, object-pair scoring, ranking, embeddings, vector indexes, and object clustering are not Exploration primitives. Spatial proximity and cluster membership carry no historical meaning.

Generated and user-composed flows are inspiration structures and always set `historicalClaim=false`. Only a future separately governed evidence-backed flow may carry a historical claim, and it must bind a governed evidence reference.

Seeded generation may select among allowed compositions. It cannot invent relation vocabulary, scholarly evidence, historical facts, directionality, or an evidence-backed status.
