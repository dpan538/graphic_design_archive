## P0 release blockers

1. Prominent `TRACE Preview — Evidence Navigation` zero relation state, on screen and export.
2. Atlas = coverage/missingness; Constellation = editorial membership; Object Trace = dossier/holds—each legend and accessible alternative says so.
3. Direct provider, supplied rights/access status, access date and no-custody copy; `UNKNOWN` is not silently rendered as clear.
4. Release-pinned count/method/source register and read-only machine metadata.
5. No legacy relation material, automated association, edge-like decoration or misleading copy.

## Explicit deferrals

- automatic influence; LLM/RAG/SLM; embedding clustering;
- old v48 graph backfill; complete ontology/RDF; user-annotation backend;
- cross-release comparison; unlimited object growth;
- 3D/WebGL; large visual redesign.

## Success metrics that matter

Report release/denominator correctness, evidence/status completeness, source/provider resolution, rights-state disclosure, zero relation count, false-inference rate in task testing, provenance-source recovery, keyboard/mobile outcomes, and documented failures. Do not use node count, animation quality, apparent density, total object count or engagement alone as research-success metrics [SR15][SR16].
