# Future Context and Spacetime contract

No live Context, Spacetime, or archive-object record is a Round 15 semantic input.

| Signal | V1 class | Future permitted use | Prohibition / next gate |
|---|---|---|---|
| period | requires future research | filter, facet, or contextual annotation after review | cannot imply chronology or override association qualification |
| geography | requires future research | map/facet/annotation after geographic uncertainty review | cannot imply diffusion, origin, or influence |
| archive collection | presentation-only | filter, source badge, viewport default | collection co-membership cannot create association |
| folder membership | semantic-forbidden | navigation only | cannot change eligibility, admission, topology, prune, split, or gap |
| context category | requires future research | reviewed facet or annotation | cannot become a latent relation type |
| Spacetime density | semantic-forbidden | possible viewport-density warning | cannot rank importance or association strength |
| object count | semantic-forbidden | possible workload/density disclosure | cannot rank concepts or choose topology |
| source family | presentation-only | provenance facet and source inspection | cannot rank historical importance; support class remains distinct |
| curatorial structure | requires future research | reviewed annotation or optional arrangement | cannot be treated as historical hierarchy |

Any use that changes historical interpretation requires a separate research round, new fixtures, human review, and a new semantic version. Round 14 qualification remains non-overridable.
