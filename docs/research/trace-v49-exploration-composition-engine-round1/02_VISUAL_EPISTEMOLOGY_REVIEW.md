# Visual epistemology review

The bounded review contains 25 methodological sources across graph drawing, interaction, uncertainty, provenance, digital humanities, and cultural-heritage interfaces. It supports policy, not new historical pair evidence.

Five findings govern V1:

- graph layout affects comprehension, but aesthetic optimization does not turn distance or position into evidence;
- visual hierarchy and force-directed placement can change historical interpretation, so topology and geometry require explicit non-claims;
- humanistic uncertainty includes source, datafication, method, and interpretation, and should remain visible rather than collapsing to a confidence number;
- provenance and workflow history are part of the visualization’s epistemic contract, not optional metadata;
- generous and semantically layered interfaces can support exploration while preserving scope, terminology, nuance, and source access.

The evidence does not justify causal arrowheads, temporal arrows, importance sizing, relation-strength line weights, force-derived centrality, or metric distance in the Round 15 renderer. It does justify a review harness with equal marks, explicit state labels, provenance access, deterministic output, and a separate presentation hash.

The source-level extraction is in `02_VISUAL_EPISTEMOLOGY_RESEARCH_MATRIX.tsv`. Confidence describes confidence in the policy implication, not the truth or importance of any historical concept.
