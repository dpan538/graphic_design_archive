# Context method statement

Context is a project-curated aid for research navigation. It shows how this archive classifies the selected public record using governed typed medium, theme, and movement-context structures derived from the frozen v49 research release. The underlying project membership row is retained as provenance, while the visible representation uses a stable public term and representation identity, a registered explanation, and an explicit governance state.

These classifications are not historical relations. A shared medium, theme, or movement context does not establish influence, contact, causation, chronology, creator intent, affiliation, or any relation between records. Movement context is specifically a project-curated research classification unless stronger evidence is separately published elsewhere. Classifications on grouped public records describe the selected public surface/group and are not automatically inherited by each member.

Geographic context is intentionally handled by the future Spacetime function instead of being duplicated in Context. Source descriptions, collections, locators, internal classification details, and other deferred evidence remain outside the public Context V1 graph.

The Context projection is release-pinned and reproducible: its manifest binds the research release, frozen inputs, eligibility ledger, governance policy, term registry, explanation registry, exception register, and generated record payload. Held records remain excluded and are indistinguishable from unknown records at the public lookup boundary.
