# Context V1 closure decision

`CONTEXT_V1_DECISION=CONTEXT_V1_CLOSED`

Context V1 is closed because its scope, epistemic role, allowed kinds, publication semantics, public identities, explanation registry, provenance contract, field decisions, movement treatment, multi-value handling, exception process, projection, read API, governed Canvas behavior, and cross-domain boundaries are explicit and reproducible.

The successful final gate requires all 22 `CTX-GOV-INV-*` invariants, the complete 7,995-object cohort, 7,928 negative held lookups, deterministic rebuild, client-corpus exclusion, API behavior, existing TRACE/Context/Search regressions, typechecks, and production build to pass. The accompanying validation document and audit package record those results.

Closure does not mean final visual release. The route remains unlinked and `noindex`; global navigation and final visual design remain deferred. Spacetime parameter governance is next. Exploration Field stays open-ended data mining.
