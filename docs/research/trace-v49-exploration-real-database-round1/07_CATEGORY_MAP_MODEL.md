# Category map model

Each category map is a bounded collection of one-composition regions. Region boundaries come from the explicit real composition registry, never unsupervised clustering. Neutral projections are presentation hints and cannot change eligibility. Maps contain at most 40 visible nodes; v1's real maps are smaller and deterministically ordered.
