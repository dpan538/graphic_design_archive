# Cross-product frontend state matrix

| Surface | Initial/loading | Populated | Zero/empty/partial | Error/fallback | State retention and boundary |
|---|---|---|---|---|---|
| Homepage Search | Four deterministic public starters; no model request. | GET form routes to canonical `/search`. | Empty text remains on homepage unless a starter/filter is selected. | Native form remains available without client guidance. | No TRACE runtime/read-model import. |
| `/search` | Bounded server request; affected region uses `aria-busy` and live status. | 25 maximum public object DTOs; plain explanation; public metadata only. | Exact zero message; absent optional credit/date/place is `Not recorded`; empty theme/movement arrays are not inferred. | Safe API detail plus retry; old results are not relabelled as current. | URL holds text, four filters, and cursor; back/forward and object return restore state. |
| Search pagination | Next cursor belongs to release, manifest, algorithm, index, and query/filter state. | New bounded page replaces the visible page. | Terminal page has no next action; previous uses browser history. | Cursor mismatch fails closed; no unbounded client index. | Maximum API page 50; reference UI uses 25. |
| Search System Suggestions | Requested only after deterministic results. | One/two sentences and 2–4 approved Search refinements when available. | May return no action when no allowed candidate exists. | No key, disabled, timeout, HTTP failure, invalid JSON/note/ID → deterministic fallback; transport failure hides guidance only. | Suggestion changes URL only after explicit click; source/status hidden. |
| TRACE mobile | Server checks mobile hints before governed data imports. | Lightweight desktop-required message links to Search. | No compressed TRACE mode. | Search remains available. | `TRACE_MOBILE_FULL_RUNTIME_ENABLED=false`. |
| Context Canvas | Governed selected-object load and local composition initialization. | Public selected label, representations, counts, and valid add-actions only. | No representation means no invented context action. | Existing fail-closed Context behavior; guidance failure has no effect. | Model cannot dispatch; user click can add only an already available representation. |
| Spacetime | Governed periods/atlas/geometry and bounded geography page loading. | Current public period/geography labels and aggregate counts only. | Zero marks/records preserve governed denominators and missingness. | Existing request-epoch/integrity behavior; guidance failure has no effect. | User click invokes only existing select/table/reset callbacks. |
| Validated Exploration | v3 product projection loads fail-closed. | Active product facts only. | Current active v3 concepts/associations/compositions are all zero; this is stated explicitly. | No synthetic control or inquiry fallback. | Guidance has `VALIDATED` evidence class and no actions when no active composition exists. |
| Open Inquiry | Fixed disclosure renders independently of guidance. | 11 bounded unresolved records; inquiry-only actions inspect evidence/source boundaries. | Null evidence remains not recorded; never inferred. | Guidance failure cannot remove or rewrite disclosure. | `OPEN_INQUIRY` evidence class; no validated topology, metric, export, or activation mutation. |

All background guidance is non-authoritative. Loading, fallback, or failure in one product surface cannot change another surface’s deterministic result or evidence state.
