# Prefreeze Main/Sub Packetization Brief v1

Date: 2026-06-19

## Purpose

This brief records the next structural direction after the pre-freeze surface
role override and main/sub/text audit.

The current candidate payload still treats most records as independent main
sheets. That is not strict enough for the archive's research model. A main
sheet should usually function as a research packet anchor: a representative
entry into a design idea, method, institution, movement, regional condition, or
visual communication problem. It should not be the default status for every
captured object.

## Working Definition

Main sheet:

- A representative anchor for a research packet.
- Supported by strong source depth, design relevance, relation density, or
  historical/region scarcity.
- Often points to a design idea or communication system through one or more
  works, not only to a single object record.
- Should support additional subsheets, cards, appendices, or editorial text
  pages when the packet grows.

Subsheet:

- A related object, variant, source view, studio/project member, campaign item,
  publication issue, or regional example that strengthens a main packet.
- Useful when the record has real source value but does not independently
  justify main-sheet status.

Card:

- A supporting note, context image, event/photo record, weak profile image,
  registry page, source trace, or small evidence item.
- Useful for keeping provenance visible without overclaiming research status.

Appendix/text:

- A source-evidence, rights-evidence, citation, metadata, typed index, or
  editorial explanation layer.
- Should support reading and verification without interrupting the primary
  object sequence.

## Promotion Factors

The next audit should rank candidate main sheets with these factors:

- Impact: known historical, institutional, formal, technological, or regional
  importance.
- Source depth: number and quality of source records, descriptions, citations,
  and rights evidence.
- Relation density: links to related works, creators, studios, schools,
  movements, campaigns, venues, publications, or regions.
- Period span: whether the packet can explain a development across time.
- Rights state: whether the visual evidence can be shown as IMG01, IMG02, or
  IMG03 without unsupported upgrading.
- Region scarcity: whether the item fills an underrepresented geography or
  archive route.
- Editorial need: whether a text page is needed to make the packet research
  readable.

## Demotion Candidates

The next pass should review these as likely non-main records:

- Single object records with thin source text and no relation signal.
- Weak context/profile/own-work images.
- Post-2010 commemorative stamp or event-image clusters unless tied to a
  stronger design packet.
- Registry, index, landing, or source pages without object-level design
  evidence.
- Repeated platform/studio records from one source family that do not add new
  research relation.

## Research Resource Integration

The archive needs a research resource layer, not only surface pages. The next
candidate audit should produce:

- Main-promotion review queue.
- Subsheet cluster suggestions.
- Card/support evidence suggestions.
- Editorial text page needs.
- Source family and institution authority summary.
- Packet confidence level: high, medium, low, or manual.

The goal is to make each mature main sheet behave like a research packet that
can be read, expanded, and audited, rather than a flat object page.

## Boundary

This is a structure and interpretation audit only. It does not download images,
does not rewrite source evidence, and does not upgrade IMG01 or IMG03 rights
states.
