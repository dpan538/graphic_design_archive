# Launch Scope v0

**Status:** Active project scope.

## Principle

The first public version should be designed as a launch-complete global framework, not as a narrow first phase with later regional additions.

This does not mean the project claims complete knowledge of every event in graphic design history. It means the database, search, source registry, coverage matrix, and design system must all be prepared from the beginning to include the known global scope of modern graphic design history.

## Launch Coverage

The launch framework includes:

- Western and Central Europe;
- Eastern Europe, Balkans, USSR, and socialist contexts;
- North America;
- Latin America and the Caribbean;
- Japan;
- Korea;
- East Asia as a transnational frame;
- Mainland China;
- Hong Kong;
- Taiwan;
- Southeast Asia;
- South Asia;
- Middle East and North Africa;
- Africa;
- Oceania and Pacific.

No region in this list is conceptually deferred.

## Readiness vs Inclusion

The project separates inclusion from readiness.

- **Inclusion:** the region, node, source need, or vocabulary area belongs in the launch framework.
- **Readiness:** the current research status of that area.

Readiness can be:

- `seeded`
- `planned`
- `launch_research_required`
- `source_mapped`
- `validated`
- `blocked`
- `out_of_scope`

This distinction prevents the project from pretending that all areas are equally researched while also preventing non-European and non-American histories from being postponed.

## Design System Consequence

The design system must assume from the start:

- multilingual labels;
- non-Latin scripts;
- right-to-left future support;
- region-specific source gaps;
- records without images;
- records with link-only rights;
- multiple calendars/date uncertainties where relevant;
- source and citation panels as first-class UI;
- coverage gaps as visible metadata, not hidden absence.

## Database Consequence

The database must include from the start:

- `regions`;
- `coverage_matrix`;
- `regional_source_priorities`;
- `classification_axes`;
- `geographies`;
- `regional_movements`;
- `regional_event_nodes`;
- `normalized_dates`;
- `entity_geographies`;
- `source_record_geographies`;
- `historical_events`;
- `coverage_gap_notes`;
- local-language search vocabulary;
- authority resolution queues;
- rights and source review tables.

## Public Claim Boundary

Allowed:

> This project launches with a global, gap-aware framework for indexing modern graphic design history across multiple regions, media, institutions, and source types.

Not allowed:

> This project fully covers every event in world graphic design history.

The project can be ambitious without pretending to be omniscient. That distinction is part of its integrity.
