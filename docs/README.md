# Documentation Index

- `methodology/` — archive methodology, image/text rules, naming rules, production workflow, and surface taxonomy.
- `system/` — database skeleton, API contract, data dictionary, search/coverage notes, source expansion, and archive-box system specifications.
- `frontend/` — interface contract, layout spec, frontend handoff notes, and field decisions.
- `capture/` — ingest reports, first capture decisions, target verification, remediation, and 1931-1970 expansion notes.
- `research-reviews/` — summaries and audits of Deep Research reports.

The project log remains at `PROJECT_LOG.md` in the repository root so collaborators can find the latest working status quickly.
