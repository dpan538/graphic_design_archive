# Error catalog

Expected codes include INVALID_CATEGORY, INVALID_VOCABULARY, INVALID_ASSOCIATION, INVALID_ACTION, ACTION_NOT_AVAILABLE, STALE_EXPLORATION_STATE, STATE_NOT_FOUND, STATE_DATABASE_VERSION_MISMATCH, REQUEST_LIMIT_EXCEEDED, INVALID_EXPORT_PRESET, NO_EXPORTABLE_COMPOSITION, HELD_DATA_BLOCKED, and INTERNAL_DATA_INTEGRITY_FAILURE. Inspect `status`, `retryable`, and `details`.
