# Product API map

This is the complete logical product API route table for Global Search, archive object/detail reading, shared System Suggestions, and all catalogued TRACE surfaces. The pre-existing exhaustive TRACE catalog remains the source for TRACE request/response detail; this map binds it into one cross-product inventory. The frontend-consumption class is a bounded handoff disposition, not a replacement for the API contract.
